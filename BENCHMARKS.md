# GPU against CPU

Generated by `make benchmark`. Do not edit by hand.

TensorFlow 2.20.0, macOS 27.0, arm64. The whole suite was run 5 times, each case 25 paired repetitions per run after 5 warmups on each device.

Both devices run the identical graph on the identical data in one process, timed alternately rather than in two phases, because timing all of one device and then all of the other turns drift between the phases into a result.

**The range is across runs, and it is wide.** That is the honest measurement, not a defect in the table: interleaving fixed the phase problem but the remaining variance is between whole runs rather than within them, so more repetitions inside a run do not narrow it. On this machine, a laptop that throttles and shares its memory bandwidth with everything else running, a case is worth believing when its range is narrow and sits clear of 1.0.

**A case marked (spans 1.0) has not been shown to be faster on either device.** Its runs landed on both sides. The median alone would hide that.

Every measurement waits for the device before stopping the clock: a Metal command buffer is asynchronous, and an unwaited timing measures how fast work can be enqueued.
